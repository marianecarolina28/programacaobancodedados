📚 Programação e Banco de Dados

Sobre o repositório

Este repositório foi criado para armazenar e organizar todos os meus trabalhos, atividades e projetos desenvolvidos na disciplina de Programação e Banco de Dados.

🎯 Objetivo

Reunir em um único lugar os materiais desenvolvidos durante meus estudos, facilitando a organização, a consulta e o acompanhamento da minha evolução na área de banco de dados.

📂 Conteúdo

Neste repositório, você encontrará:

- Trabalhos e atividades da disciplina;
- Scripts SQL;
- Criação e estruturação de bancos de dados;
- Consultas e comandos SQL;
- Modelagem de bancos de dados;
- Exercícios e projetos acadêmicos;
- Outros materiais relacionados à disciplina.

🛠️ Tecnologias e ferramentas

- MySQL
- SQL
- MySQL Workbench e/ou phpMyAdmin, conforme a atividade;
- Git e GitHub para organização e armazenamento dos trabalhos.
